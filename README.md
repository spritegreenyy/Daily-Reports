# WINDRISE Daily Research Terminal

面向大宗商品研究与交易观察的自动化日报系统。项目将分散的行情、持仓和公开观点转化为结构化信号，并通过可交互网页持续归档，便于快速复核、横向比较和后续回测。

## 在线访问

**[打开 WINDRISE 日报台](https://spritegreenyy.github.io/Daily-Reports/)**

日报台支持按日期浏览、中文与英文切换，并适配桌面端和移动端。报告采用自包含 HTML，核心图表与交互逻辑随文件归档，便于长期复查。

## 核心内容

### 资金潮汐

- 跟踪机构、外资及区域性席位在重点期货品种上的持仓变化。
- 展示净持仓、净持仓变化、多头变化、空头变化与名义规模。
- 按板块扫描信号与后续价格表现，使用 IC、胜率和样本量筛选更具解释力的结果。
- 支持品种搜索、动作筛选、相关性排序及历史持仓曲线查看。

### 期货形态

- 覆盖15个重点品种，以4小时K线为统一观察周期。
- 使用 ATR ZigZag 枢轴、轨道几何和收盘突破规则识别三角形、矩形、楔形、旗形等结构。
- 每个品种可保留多个互不高度重叠的近期形态，并区分“形成中”与“突破已确认”。
- 按结构置信度排序待突破机会，给出上轨、下轨、条件化方向和失效提醒。
- 支持从摘要一键定位到对应K线图，主结构与次级结构分层显示。

### KOL 观点

- 将公开市场观点按宏观经济、地缘政治、大宗商品、天气气候和科技主题分类。
- 提炼核心观点与交易含义，同时保留原始来源供复核。
- 将自然语言观点转化为可回测的方向指数，并单独覆盖软商品相关内容。
- 强调观点语义而非数字堆叠，避免将普通数值误识别为核心结论。

## 方法框架

项目遵循“数据检查 → 结构识别 → 证据确认 → 条件化场景 → 历史验证”的研究流程：

1. 检查数据截止时间、样本完整性和异常值。
2. 优先分析趋势、市场结构与关键支撑阻力，再使用指标作为辅助证据。
3. 将形成中的倾向与已经确认的突破严格区分。
4. 明确触发条件、失效条件和假突破风险，不输出无条件涨跌预测。
5. 通过滚动回测、IC、胜率和样本量评估信号是否具备稳定性。

## 工程实现

- Python 完成数据获取、清洗、结构识别、回测和报告生成。
- HTML、CSS 与 JavaScript 构建自包含的双语交互终端。
- Matplotlib 生成K线、量能、持仓量和结构边界图。
- GitHub Pages 提供公开访问，日报按日期自动归档并更新最新入口。
- 自动化流程依次生成形态、资金潮汐和KOL报告，并执行测试、站点构建和版本同步。

## 可迁移价值

- 将定性研究要求转化为可重复执行的量化规则。
- 将行情、持仓和文本观点统一为可比较、可追溯的数据结构。
- 通过“候选—确认—失效—回测”框架降低主观判断的不一致性。
- 报告生成、双语展示、历史归档和网页发布可复用于其他资产类别或研究主题。

## 数据与风险说明

本项目用于研究展示与方法验证。公开行情、席位和观点数据可能存在延迟、缺失或口径差异；形态置信度不等于上涨概率或历史胜率，所有方向提示均为条件化场景，不构成投资建议。
